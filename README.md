# All Translator

A Minecraft mod that translates Minecraft/mod language files, item and block
names, tooltips, entity names, UI text, chat, and FTB Quests content using
translation APIs supplied and configured by the user.

Built with [Architectury](https://docs.architectury.dev/), targeting Fabric
and NeoForge.

See `ARCHITECTURE.md` for the technical design and `DEVELOPMENT_STATUS.md`
for current implementation progress.

## Building

```bash
./gradlew build
```

Platform jars are produced under `fabric/build/libs/` and
`neoforge/build/libs/`.

## Status

This project is under active phased development. See
`DEVELOPMENT_STATUS.md` for the current phase and implemented features.
